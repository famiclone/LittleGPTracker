# Garlic OS

## Installation

1. Copy lgpt-rg35xxplus.elf, config.xml, samplelib, lgpt_BETA to /SdCard/Roms/APPS/lgpt/
2. Copy lgpt.png to /SdCard/Roms/Imgs/
3. Copy SwineTracker-garlicos.sh to /SdCard/Roms/

## Usage

Open "Consoles -> Apps -> SwineTracker".

# muOS

## Installation

1. Copy lgpt-rg35xxplus.elf, config.xml, samplelib, lgpt_BETA to /mnt/mmc/MUOS/application/.lgpt/
3. Copy SwineTracker-muos.sh to /mnt/mmc/MUOS/application/

## Usage

Open "Applications -> SwineTracker".
